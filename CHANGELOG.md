# Changelog

## 1.2.0 — 2026-10-12

- Reoriented core around **Value → Cut → Ship → Stop** and diminishing-return stop rule; **Flash is the default**.
- Removed mandatory planning/grilling/verification ceremony on trivial and low-risk tasks; added proportionate-check guidance.
- Preserved explicit full-scope requirements, safety, security, accessibility and correctness as hard constraints.
- Revised benchmark to assess **quality-gated elapsed time and token efficiency**, with per-arm blind usability flags and task-bootstrap paired ratios.
- Added realistic MVP-vs-ALL Plotly decision scenarios; refreshed bilingual README, examples, docs and four-step SVG.
- No real-model efficacy results are claimed; comparison with v1.1 must be a separate frozen experiment.

## 1.1.0 — 2026-10-11

- Removed all product-specific/private-project macro analytics examples across the public skill, docs and tests.
- Added 30-case prospective A/B/C benchmark harness (20 executable code cases, 10 decision/control cases).
- Added CLI adapters, fresh trial workspaces, independent oracles, blind judge export/import, real JSONL traces, telemetry and self-contained HTML charts.
- Added preregistered efficacy gate, safety cautions and offline harness regression tests.
- No empirical model performance claims until real experiments and independent audit are complete.

## 1.0.0 — 2026-10-11

- Initial portable Pareto-first decision skill: Outcome, Leverage, Challenge, Minimize, Verify.
- Flash / Focus / Deep modes with non-negotiable constraint guardrails.
- Independent adversarial interview protocol inspired by Grill Me.
- Optional zero-dependency ranking CLI with mandatory work and dependency checks.
- Offline installation, unit tests, prospective behavioral evaluations, research and design audit.
- GitHub-first bilingual README, original logo with dark-mode adaptation, and five-gate workflow illustration.
