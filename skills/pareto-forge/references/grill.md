# Optional challenge / Grill — earn the overhead

Use **only** if a hidden assumption could cause substantial wasted work, risk, or irreversible harm, or the user explicitly asks for critique. This is an original self-contained protocol inspired by questioning skills, with no runtime dependency on another skill.

Before asking anything, inspect available evidence. Then identify the **single highest-consequence unknown** and either:
- check it cheaply yourself;
- ask one targeted question with a sensible default;
- run the smallest falsifiable experiment; or
- document the risk and proceed reversibly if safe.

For truly high-stakes choices, additionally check downside, dependencies, alternatives, rollback and decision owner using `assets/decision-record.md`. Stop grilling as soon as the answer no longer changes the next useful action.

Do **not** grill users about optional colors, filenames, minor polish or hypothetical five-year scaling when building a simple demonstration. Questions and long reasoning cost time and tokens.
