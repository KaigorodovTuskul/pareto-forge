# Pareto Forge — быстрый старт v1.2

**Цель:** как можно раньше дать полезный рабочий результат и прекратить необязательную полировку. 80/20 — эвристика, не гарантия экономии.

## Логика

1. **Value:** сформулировать практическую пользу и обязательные требования.
2. **Cut:** исключить необязательные затраты, переиспользовать готовое.
3. **Ship:** сразу сделать минимально полезную реализацию.
4. **Stop:** выполнить пропорциональную проверку и завершить работу.

**Flash (по умолчанию)** — сразу выполнить простую задачу. **Focus** — только когда требуется короткое сравнение. **Deep** — когда высоки риски или пользователь явно просит аудит.

## Установка

```bash
npx skills add KaigorodovTuskul/pareto-forge --skill pareto-forge
```

Офлайн-установка из репозитория (Python 3.9+):

```bash
python scripts/install.py --project /path/to/your/project
```

Список аргументов: `python scripts/install.py --help`.

## Пример запроса

> Pareto Forge: сделай самый быстрый работающий прототип. Не трать время на необязательные функции, дополнительные тестовые системы и сложную архитектуру. Проверь только главное и остановись.

Если прямо требуется полный охват, работа с данными пользователей или производственная надёжность, эти ограничения остаются обязательными. Никакой экономии токенов пока не доказано. Методика испытаний — в [Benchmark Lab](../benchmark/README.md).
