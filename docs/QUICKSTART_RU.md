# Pareto Forge — быстрый старт

**Скилл для AI-агентов, который сочетает Парето, критический аудит решений и минимально достаточную реализацию.**

## Логика

1. **Outcome:** определить полезный результат и обязательные ограничения.
2. **Leverage:** выбрать немногочисленные действия с максимальной ожидаемой пользой.
3. **Challenge:** проверить гипотезы и риски в духе Grill Me, не превращая работу в бесконечное интервью.
4. **Minimize:** в духе Ponytail сначала убрать/переиспользовать, затем добавлять код.
5. **Verify:** проверить, достигнут ли результат; не обещать измеренную эффективность без тестов.

Режимы: **Flash** (простые задачи), **Focus** (по умолчанию), **Deep** (существенные или дорогие решения). Принцип «80/20» — эвристика, а не гарантированный результат.

## Установка

После публикации репозитория:

```bash
npx skills add KaigorodovTuskul/pareto-forge --skill pareto-forge
```

Или прямо из распакованного архива, без npm:

```bash
python scripts/install.py --project /path/to/your/project
```

Для Claude Code:

```bash
python scripts/install.py --project /path/to/your/project --agent claude-code
```

Для просмотра доступных параметров: `python scripts/install.py --help`.

## Примеры запросов

- «Примени Pareto Forge: что из этих 15 задач стоит делать первым и почему?»
- «Pareto Forge, Deep: раскритикуй архитектуру сложного onboarding workflow; предложи минимальный валидируемый MVP».
- «Pareto Forge, Flash: упрости эту функцию, не нарушив безопасность и тесты».

## Важное ограничение

Наличие корректного `SKILL.md` не доказывает, что все агенты его автоматически загружают. `skills.sh` поддерживает широкий перечень клиентов, но поведение нужно проверять в конкретной версии. В папке [`docs/`](.) лежат обзор референсов, архитектурный аудит и методика тестирования.

## Бенчмарк эффективности

В [`benchmark/`](../benchmark/README.md) есть 30 задач, реальный A/B/C-раннер, объективные тесты кода и слепое сравнение решений. До выполнения независимых испытаний никаких заявлений о росте качества/экономии токенов нет.
